# Password Generator
This project is created using Python for the CodSoft Artificial Intelligence Internship.
## Description
The Smart Password Generator creates strong and secure passwords based on user preferences. Users can choose whether to include uppercase letters, lowercase letters, numbers, and special symbols in the password.

## Features
- Strong password generation
- User-friendly interface
- Password strength checker
- Security tips for users
- Custom password options
- Random and secure passwords

## Technologies Used
- Python

## How to Run

1. Open terminal
2. Run the following command:

python password_generator.py

Enter password length: 10

Generated Password:
