# Tic-Tac-Toe AI

This project is created using Python for the CodSoft Artificial Intelligence Internship.
## Description
This is a simple Tic-Tac-Toe game where the user plays against the computer. The AI can block player moves, try to win the game, and make intelligent decisions.

## Features
- Human vs Computer gameplay
- Smart AI moves
- Winner detection
- Draw detection
- User-friendly console interface

## Technologies Used
- Python

## How to Run
1. Open terminal
2. Run the following command:

python tictactoe.py
