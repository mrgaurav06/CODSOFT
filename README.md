# Rule-Based Chatbot

This project is created using Python for the CodSoft Artificial Intelligence Internship.

## Description
The chatbot responds to user inputs using predefined rules and conditions. It can answer simple questions, perform basic calculations, tell jokes, show date and time, and respond to weather-related queries.

## Features
- Greetings and conversations
- Date and time display
- Weather and temperature responses
- Basic mathematical calculations
- AI and Python related questions
- Motivation and jokes

## Technologies Used
- Python
